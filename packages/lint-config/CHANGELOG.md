# @yas chat/lint-config

## 0.1.0

### Minor Changes

- ([#43037](https://github.com/YasChat/YasChat/pull/43037)) Adds an opt-in `spacing-scale` rule, exported from `@yas chat/lint-config/rules` as an oxlint JS plugin, that reports literal spacing values that aren't Fuselage spacing tokens

- ([#43010](https://github.com/YasChat/YasChat/pull/43010)) Adds `@yas chat/lint-config`, YasChat's shared oxlint config (`@yas chat/lint-config/oxlint.json`), replacing `@yas chat/eslint-config`.
